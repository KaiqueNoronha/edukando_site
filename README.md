# Edukando — Landing institucional

Site institucional da Edukando em Next.js, fiel ao protótipo.

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Deploy (AWS S3 + CloudFront)

```bash
./deploy/aws/setup.sh   # uma vez
./deploy/aws/deploy.sh  # publicar
```

Detalhes em [`deploy/DEPLOY.md`](deploy/DEPLOY.md).
